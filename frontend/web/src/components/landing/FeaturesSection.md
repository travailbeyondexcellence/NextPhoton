# FeaturesSection Component

## Overview
Features section showcasing platform capabilities for landing page.

## Location
`/components/landing/FeaturesSection.tsx`

## Purpose
Display key features with icons, descriptions, and animations for marketing pages.

## Key Features
- Feature grid layout
- Icon-based feature cards
- ScrollReveal animations
- Gradient color accents per feature
- Lucide icons (Users, BarChart3, Calendar, Shield, etc.)

## Dependencies
- framer-motion
- ScrollReveal animation
- lucide-react icons

## Features Displayed
- Multi-Role Platform
- Real-Time Analytics
- Smart Scheduling
- ABAC Security
- Instant Communication
- And more...

## Interactions with Sister Components

### HeroSection (Sister)
**Relationship**: Sequential landing sections
- HeroSection → FeaturesSection
- Part of landing page flow

### PricingSection (Sister)
**Relationship**: Landing page siblings
- Often used together on landing pages

## Common Use Cases
- Landing pages
- Marketing pages
- Product pages
- Homepage
