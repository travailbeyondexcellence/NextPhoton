# TestimonialsSection Component

## Overview
Customer testimonials section for landing pages.

## Location
`/components/landing/TestimonialsSection.tsx`

## Purpose
Display social proof through customer testimonials and reviews.

## Key Features
- Customer testimonials grid/carousel
- Customer photos/avatars
- Star ratings
- Customer names and roles
- Company information
- ScrollReveal animations
- Quote formatting

## Dependencies
- framer-motion
- ScrollReveal animation
- lucide-react icons (Star, Quote)
- GlassCard or similar for testimonial cards

## Testimonial Card Structure
- Customer quote
- Star rating
- Customer name
- Customer role/title
- Company name
- Optional photo/avatar

## Interactions with Sister Components

### PricingSection (Sister)
**Relationship**: Sequential landing sections
- Often follows pricing or features

### FeaturesSection (Sister)
**Relationship**: Landing page siblings
- Part of landing page flow

### GlassCard (Possible)
**Relationship**: May use for testimonial cards

## Common Use Cases
- Landing pages
- About pages
- Product pages
- Sales pages
- Social proof sections

## Layout Options
- Grid layout
- Carousel/slider
- Masonry layout
- Staggered animations
